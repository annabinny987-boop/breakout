# Breakout Game

A simple Breakout game made using Godot Engine as part of the 20 Games Making Challenge.

# Game Features

- Classic Breakout gameplay
- Player-controlled paddle
- Ball movement and bouncing
- Ball bounces off walls, ceiling and paddle
- Bricks arranged in rows
- Bricks disappear when hit by the ball
- Score increases when bricks are destroyed
- Ball speed increases as bricks are broken
- 3 lives system
- Game over condition
- Restart option
- Score and lives displayed on screen
- Simple and clean 2D game design

# Controls

# Player

- ← Left Arrow – Move paddle left
- → Right Arrow – Move paddle right

# Restart

R– Restart the game


# What I Learned

Through this project, I learned the basics of 2D game development, including:

- Creating a 2D game in Godot
- Using GDScript
- Handling keyboard input
- Moving game objects
- Implementing ball physics and bouncing
- Detecting collisions
- Creating and managing bricks
- Removing bricks after collision
- Creating a scoring system
- Managing player lives
- Increasing ball speed during gameplay
- Creating game-over conditions
- Restarting the game
- Debugging and testing game mechanics

# Challenges Faced

The main challenges I faced were getting the ball movement and collision detection working correctly.

I also had to handle the paddle movement, brick destruction, scoring system, lives, and game-over condition.

By testing and debugging different parts of the game, I was able to fix the issues and complete the game successfully.
